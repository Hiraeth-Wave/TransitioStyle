# TransitioStyle

Hira 个人自用的 [Transitio](https://github.com/PRO-2684/transitio) 样式。\
开发这些样式使用的 QQ 版本为 9.9.33-52230，QwQNT Core & Framework 版本为 0.1.0，Transitio 版本为 1.6.0。

## Option Simplifier

forked from [YatFanLan/Simplify-chat-boxes](https://github.com/YatFanLan/Simplify-chat-boxes)，复刻了轻量工具箱的侧栏/输入框/聊天框精简功能并在此之上进行了扩展，支持隐藏大部分界面上的功能按钮，同时提供了丰富的配置项，可以自由定义隐藏哪些按钮。

## Rounded Avatar Next

forked from [Candquarzy/Rounded_Avatar_For_QQNT](https://github.com/Candquarzy/Rounded_Avatar_For_QQNT)，使各种各样的头像变为圆角矩形。
